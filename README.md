Схема пешего туристического маршрута по центру Иркутска

Задача
Разработать карту-схему пешего маршрута по историческому центру Иркутска с указанием основных достопримечательностей и объектов туристической инфраструктуры.

Данные
OpenStreetMap (через QuickOSM): музеи, парки, церкви, обзорные точки гостиницы.

Подложка: CartoDB Positron (no labels) — чистая основа без подписей.

Маршрут: оцифрован вручную по улицам города.

Инструменты
QGIS 4.2

QuickOSM

CartoDB Positron (XYZ Tiles)

Print Layout

Inkskape

Результат
Карта-схема в формате JPEG (300 dpi).

11 точек интереса: музеи, церкви, обзорные точки, гостиницы.

Линия пешего маршрута.

Легенда по категориям объектов.

Врезка с расположением района в городе.

Примерное время прохождения маршрута: ~5 часов.
